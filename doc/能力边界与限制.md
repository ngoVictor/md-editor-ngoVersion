# 能力边界与限制

以下门禁以链接的源码为依据。本文集中维护门禁和语义；实现变化时修改对应行，不在各指南重复追加数字。容量使用 **MiB = 1024² 字节**；UI 中部分提示写作 MB。

## 文件、编辑与恢复

| 项目 | 当前边界 | 实现依据 |
| --- | --- | --- |
| Markdown 打开/保存 | md/markdown/mdown/txt，大小写不敏感；打开原始字节及保存 UTF-8 字节均不超过 20 MiB | [lib.rs](../src-tauri/src/lib.rs) |
| 编码 | Markdown：UTF-8 BOM / UTF-8 / 无效 UTF-8 回落 GBK；BOM 后损坏的 UTF-8 或不能完整解码的 GBK 拒绝打开/恢复，不用替换字符改写原文；保存统一 UTF-8 无 BOM。源码预览另支持带 BOM UTF-16 | [lib.rs](../src-tauri/src/lib.rs)、[resources.rs](../src-tauri/src/resources.rs) |
| 一致性读取 | 最多 3 轮，每轮连续两次读取内容指纹、大小、路径身份相同才提交 | [lib.rs](../src-tauri/src/lib.rs) |
| 指纹 | FNV-1a 64 位用于本地修改检测，不是安全哈希；pathKey 由 Rust 规范化，mtime/size 不替代指纹 | [lib.rs](../src-tauri/src/lib.rs) |
| 延迟输入同步 | 正文长度 >262144 个 JS 字符时延迟 1500 ms；保存、切换、查找和导出主动同步 | [editor-sync.ts](../src/editor-sync.ts) |
| 撤销 | 每文档最多 100 个 undo 快照，undo/redo 合计按 UTF-16 估算限制 16 MiB；不是无限撤销 | [history.ts](../src/history.ts) |
| 源码查找 | UTF-8 估算输入 5 MiB；最多 10,000 个匹配；Worker 1500 ms 超时终止；截断结果不能替换 | [find.ts](../src/find.ts)、[find-engine.ts](../src/find-engine.ts) |
| 替换输出 | 最多 5×1024² 个 JS 字符（与字节上限不同）；保存仍检查 UTF-8 字节 | [find-engine.ts](../src/find-engine.ts) |
| 自动保存/外改 | 自动保存默认关闭，30 秒及失焦/隐藏触发；外改每 15 秒及聚焦/切换检查激活文档 | [autosave.ts](../src/autosave.ts)、[external-changes.ts](../src/external-changes.ts) |
| 会话 | 默认关闭；最多 50 个有路径标签及激活路径；不保存正文、未命名草稿或跨启动滚动位置 | [session.ts](../src/session.ts) |
| 文件历史 | 单份原始内容 20 MiB；每路径最多 50 份、合计 64 MiB、保留期 30 天；在该路径下次归档时清理，非常驻全局清理 | [history.rs](../src-tauri/src/history.rs) |
| 历史恢复 | 前端预览最多展示 20,000 字符；恢复使用读取的完整内容，先成为未保存修改并暂停后台保存 | [history-view.ts](../src/history-view.ts) |

文档尚未编辑时保存原始正文，避免挂载序列化静默规范化；章节操作使用 splitLines/joinLines 保留所选 CRLF/LF。实际编辑经 Vditor 序列化，不承诺混合换行或所有编辑场景的逐字节往返。

## 导出与图片

| 项目 | 当前边界 | 实现依据 |
| --- | --- | --- |
| 所有导出入口 | 捕获 Markdown UTF-8 字节不超过 5 MiB；合成输入、重建、窗口转移或文档未就绪时不开始 | [export-snapshot.ts](../src/export-snapshot.ts) |
| HTML / PDF / 打印 HTML | 不超过 16 MiB；HTML 只写 html/htm | [export.rs](../src-tauri/src/export.rs)、[pdf.rs](../src-tauri/src/pdf.rs)、[output.rs](../src-tauri/src/output.rs) |
| Word / PDF / PNG 成品 | 解码或成品字节不超过 64 MiB；分别限定 docx/pdf/png | [lib.rs](../src-tauri/src/lib.rs)、[pdf.rs](../src-tauri/src/pdf.rs)、[output.rs](../src-tauri/src/output.rs) |
| PDF | 全进程单任务；隐藏 WebView2 PrintToPdf 等待 120 秒，源窗口销毁时取消；无外部 Edge exe 方案 | [pdf_webview.rs](../src-tauri/src/pdf_webview.rs) |
| PNG | 前端宽 1000 px，高最多 16000 px，总计最多 1600 万像素；Rust 另校验像素总量 | [export-png.ts](../src/export-png.ts)、[output.rs](../src-tauri/src/output.rs) |
| 系统打印 | 最多 4 个 print-* 窗口；打开打印界面等待 30 秒；成功仅代表界面打开，完成/取消后需关闭承载窗口 | [output.rs](../src-tauri/src/output.rs) |
| Word 表格 | A4 可用宽度 8306 twips；边框、tblGrid 与 tcW 一致；新后端和兼容后端均需守住 | [docx-tokens.ts](../src/docx-tokens.ts)、[docx.ts](../src/docx.ts) |
| 本地嵌图 | PNG/JPEG/GIF/WebP、有效栅格 data URI；单图 4 MiB，最长边 8192 px，总计 1600 万像素；解码等待 10 秒 | [assets.rs](../src-tauri/src/assets.rs)、[raster-image.ts](../src/raster-image.ts) |
| 导出嵌图预算 | 前 64 个图片位置；data URI 字符串合计 8 MiB，重复位置也计入；失败降为说明并提示 | [export-assets.ts](../src/export-assets.ts) |
| 本地编辑图片显示 | 前 64 个位置；本次缓存 URI 字符串最多 8 MiB、累计显示最多 1600 万像素；只用 srcset 显示，不写回源码 | [editor-images.ts](../src/editor-images.ts) |
| 在线图片显示 | HTTP/HTTPS 地址由 WebView 直接加载，可显示远程 SVG 徽章；依赖网络，不自动落盘，不适用本地解码预算 | [tauri.conf.json](../src-tauri/tauri.conf.json) |
| HTML 混排 | 支持独立 HTML 块及跨段落的成对 div align（left/center/right）、center；未闭合容器不扩散对齐，非完整网页浏览器 | [editor-html.ts](../src/editor-html.ts) |
| 粘贴/迁移 | 一次最多粘贴 8 张；另存为最多 64 个 Markdown 图片引用位置；资源按内容 SHA-256 寻址，不覆盖不同内容 | [editor-images.ts](../src/editor-images.ts)、[image-migration.ts](../src/image-migration.ts)、[assets.rs](../src-tauri/src/assets.rs) |
| 公式/Mermaid | 单个源码最多 16000 个 JS 字符（提示写作 16 KB），每次最多 32 个；Mermaid 严格模式、最多 200 边；中间图不超过 400 万像素/8192 px 每边 | [export-specials.ts](../src/export-specials.ts) |

本地栅格图片导出不包含远程、SVG/BMP。图表内部的 SVG 转 PNG 属于受控生成过程，不表示支持任意 SVG 附件嵌入。Word 图像是 PNG 静态画面；公式不是可编辑 Word 数学对象。图片取读取时内容，不保证多个资源在同一瞬间形成文件系统快照。

另存为改写 Markdown 图片节点/引用定义，保留其他源码；远程引用不迁移，原始 HTML img 不参与迁移。缺失或不支持的本地 Markdown 图片会阻止迁移。原图片不删除，未命名 image-drafts 和失败遗留资源没有自动清理。

## 导航与窗口

| 项目 | 当前边界 | 实现依据 |
| --- | --- | --- |
| 外链 | 仅 http/https/mailto/tel；主程序接管，不依赖 Vditor window.open | [link.ts](../src/link.ts) |
| 分类本地链接/图片/目录 | 本机盘符路径；拒绝 UNC、设备路径、ADS 和非法字符；资源操作 canonicalize 后重新分类 | [link-target.ts](../src/link-target.ts)、[local_path.rs](../src-tauri/src/local_path.rs)、[resources.rs](../src-tauri/src/resources.rs) |
| 附件打开 | PDF/Office/常见图片固定后缀白名单；程序、快捷方式和未知类型拒绝；脚本仅作源码查看 | [resources.rs](../src-tauri/src/resources.rs) |
| 源码预览 | 2 MiB 文本，一次最多 400 行；支持 :行[:列]、#L行；超出末行提示并定位末行；最多 12 个独立窗口 | [source-preview-view.ts](../src/source-preview-view.ts)、[preview_windows.rs](../src-tauri/src/preview_windows.rs) |
| 最近文件/目录 | 最近 30 个路径；单目录枚举最多 2000 项；跳过点开头项、指定构建目录、符号链接及 reparse point，不等同跳过所有 Windows hidden 属性文件 | [recent-files.ts](../src/recent-files.ts)、[navigation.rs](../src-tauri/src/navigation.rs) |
| 目录搜索 | 查询 1–256 字符；约 2000 项、深度 8、100 条结果、每文件 10 条、UTF-16 内容估算约 16 MiB、15 秒预算；按有界 IPC 间隙检查，非硬实时上限 | [directory-search.ts](../src/directory-search.ts) |
| 窗口转移 | 源窗口至少 2 标签；序列化载荷 96 MiB；等待目标约 20 秒，接收侧约 25 秒（另加 IPC 耗时）；不支持拖回合并 | [window-transfer.ts](../src/window-transfer.ts)、[windows.rs](../src-tauri/src/windows.rs) |
| 主题/大纲宽度 | 默认浅色；system 只解析成浅/深；五套六级标题颜色。大纲宽度限制 150–480 px，默认 240 px | [preferences.ts](../src/preferences.ts)、[theme-palette.ts](../src/theme-palette.ts) |

上述盘符限制属于分类导航、图片、目录与相关输出服务，不能概括成所有 Markdown open_file/save_file 都调用了 local_path 校验；它们仍使用自身扩展名、pathKey 与内容门禁。

目录搜索是有界即时扫描，正文资格共用 Rust 本地资源分类（Markdown 和受支持源码），行号兼容 CR、CRLF、LF；取消后忽略迟到结果，正在执行的单个 IPC 不会被强杀。源码预览不跟踪外改、不恢复到下次启动；拆分窗口不恢复/覆盖主窗口会话。
