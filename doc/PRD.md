# md-editor 产品需求文档（当前实现）

Windows 10/11 + WebView2，版本字段 `0.1.0`。本文描述当前实现；最近一次正式构建的验证范围见[交付记录](资料/维护/MD图标与Claude主题交付-20261110/交付说明.md)。

## 1. 定位与目标

面向本地写作、技术文档和办公交付的离线 Markdown 桌面编辑器。以免安装的单文件 exe 交付，运行依赖 Windows WebView2 Runtime；偏好、文件历史和未命名图片资源仍使用应用本地数据目录，不是将所有数据放在 exe 旁。

核心目标：三种编辑视图共用可靠的文档状态；本地打开、保存与冲突处理可控；支持中文复制及多格式输出；无需账号或联网完成核心工作。

## 2. 已交付需求与验收

| ID | 能力 | 当前验收口径 |
| --- | --- | --- |
| FR-001 | 打开文件 | md/markdown/mdown/txt；选择、原生拖放、命令行首个合法文件及单实例转发；UTF-8/BOM/GBK |
| FR-002 | 多标签 | Rust pathKey 去重；普通重复打开 dirty 只激活、clean 原子重载正文及基线；链接导航到已加载文档只激活 |
| FR-003 | 保存与另存为 | UTF-8 无 BOM；逐文档串行；Rust 内容指纹检查与原子替换；失败或取消不提交新身份；显式确认清空和外改覆盖 |
| FR-004 | 关闭保护 | 逐标签及窗口关闭提供保存、放弃、取消；选择保存须将最新修改落盘；保留保存全部，已移除三个批量关闭入口 |
| FR-005 | 窗口拆分 | 至少两个标签时拖出；新窗口就绪并提交后才移除源标签；转移草稿、撤销、滚动和磁盘基线；失败回退 |
| FR-101 | 三模式 | 排版成品 WYSIWYG、语法编辑 IR、分屏预览 SV；切换同步并恢复滚动；模式/语言重建按末次意图推进 |
| FR-102 | 文档撤销 | 每文档独立、有界；跨标签/模式保留；替换、表格和大纲操作可撤销；撤回保存内容重新计算 dirty |
| FR-103 | 查找替换 | 三模式均搜索 Markdown 源码；字面量、大小写、正则、上下项和替换；Worker 可终止，过期结果不提交 |
| FR-104 | 表格 | WYSIWYG 行列增删、对齐、数字操作、数据行上下移动；表头不移动；三模式宽表可横向滚动 |
| FR-105 | 大纲 | ATX 标题定位、过滤、章节删除及重排；围栏解析、稳定章节身份；宽度可调整并记忆 |
| FR-106 | 链接与资源 | 文档内/跨文档锚点；本地文档、源码、附件和目录分类导航；安全外链交系统应用；迟到结果不抢导航 |
| FR-107 | 源码预览 | 独立只读原生窗口，可多开、移动和缩放；不产生可保存文档；可指定代码编辑器并保留行列定位 |
| FR-201 | 复制 | 渲染/源码双模式；富文本和纯文本输出；显式保留有序列表数字；记住选择 |
| FR-202 | 三语与主题 | 简中/繁中/英文；浅色/深色/护眼绿/暖纸/Claude Code 及跟随系统；H1–H6 独立配色；主题跨窗口同步并持久化 |
| FR-203 | 多格式输出 | 统一格式框：HTML 带样式/纯净、Word 默认 token/兼容 HTML 后端、PNG、打印、PDF；使用捕获快照 |
| FR-204 | Word 排版 | 默认后端原生编号和脚注、中文字体、代码高亮、引用、表格显式边框与 A4 列宽；复杂 HTML 可手选兼容后端 |
| FR-205 | 图片与图表 | 本地栅格图及 data URI 导出；剪贴板图片插入、三模式显示；HTTP/HTTPS 在线图片与 SVG 徽章显示；README 的 HTML 标题和成对对齐容器混排；首次保存/另存为迁移本地图片；公式/Mermaid 离线栅格化 |
| FR-301 | 自动保存 | 默认关闭；开启后周期/失焦触发既有保存队列；空白、未命名、外改、错误等不后台强制覆盖 |
| FR-302 | 文件标签恢复 | 默认关闭；只存有路径标签和激活项；启动按需加载，不持久化未保存正文；拆分窗口不恢复主会话 |
| FR-303 | 文件历史 | 覆盖前归档原始字节；失败阻止覆盖；历史恢复先成为可撤销修改并暂停后台保存，手动保存后才落盘 |
| FR-304 | 只读文件导航 | 最近文件、目录浏览、名称/正文有界搜索；支持取消及截断提示；不维护全盘后台索引 |

## 3. 非功能要求

| ID | 要求 | 验收口径 |
| --- | --- | --- |
| NFR-001 | 离线与隐私 | 核心编辑、公式/图表渲染和输出离线可用；文档引用的在线图片由 WebView 加载，导出不下载远程资源；不上传正文；生产版隐藏诊断入口 |
| NFR-002 | 安全 | 主应用 CSP、外链协议白名单、分类本地资源检查；导出净化 HTML，PDF/打印窗口禁脚本且不授予编辑器 capability |
| NFR-003 | 数据完整性 | 身份/正文/revision/dirty/基线经 store 提交；异步操作核对文档及版本；冲突与清空需用户明确确认 |
| NFR-004 | 有界资源 | 文件、导出、图片、搜索、撤销、历史和窗口均有门禁；具体数值只维护在[能力边界与限制](能力边界与限制.md) |
| NFR-005 | 可维护性 | TypeScript strict、模块 import 无环、文件 IPC 集中适配、源码预览与编辑生命周期隔离；有仓库内回归测试 |
| NFR-006 | 可交付性 | 正式便携 exe 经 Tauri 构建并核验哈希；资源或 release 配置变化须验证正式 exe，而非只验证开发服务器 |

## 4. 范围决策

**已完成**：编辑与保存、多窗口、统一导出、分类导航、五套主题与 MD 图标。离线资源采用运行时清单，release 使用体积优化配置。

**已取消**：磁盘文件删除/重命名、全盘索引、便携 Data 设置、诊断包。另存为与只读导航不受此决策影响。

**当前未提供且未承诺**：未保存草稿的崩溃恢复、跨窗口合并、任意社区 CSS、云同步、多人协作、插件市场、其他平台正式发行。列宽拖动、阅读增强等不属于已交付功能。

## 5. 发布验收与成功口径

执行[构建与发布检查](构建exe全流程.md)，重点复验保存期间继续编辑、外改冲突、空白确认、另存为失败、窗口转移回退、历史恢复和关闭取消。编辑检查覆盖三模式、三语言、五套主题、复制、大纲、表格及本地链接；输出检查覆盖两套 Word 后端、HTML、PDF、PNG 和打印界面。

验收结论必须区分源码确认、浏览器 fake、Rust 单元、真实 release IPC 与人工系统交互。历史样例通过不等于覆盖所有 IME、DPI、Word/WPS、WebView2 或打印驱动。开放边界见[能力边界与限制](能力边界与限制.md)，发布时按[构建指南](构建exe全流程.md)重新验证。
