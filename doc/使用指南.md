# MD 编辑器使用指南

适用于当前阿雷整合版。版本字段为 `0.1.0`；功能范围见 [PRD](PRD.md)，大小/数量等精确上限见[能力边界与限制](能力边界与限制.md)。

## 1. 开始使用与界面

在有 WebView2 Runtime 的 Windows 上双击便携 exe，点击“打开”或将 Markdown 文件拖入窗口。默认使用“排版成品”；编辑后 Ctrl+S 保存，无路径时选择保存位置。命令行可用 `md-editor.exe "D:\笔记\方案.md"`，取参数中首个存在且合法的文件。程序已运行时会转发给一个编辑器窗口；标签拖出才创建新的编辑器窗口。

| 区域 | 控件与用途 |
| --- | --- |
| 顶部 | 新建、打开、保存、编辑模式、模式徽标、复制模式、语言、文件名和编码 |
| 标签栏 | 切换文档；未保存标记；逐标签 × 关闭；拖出到新窗口 |
| 辅助栏 | 文件导航、查找替换、历史版本、格式框与导出、保存全部、自动保存、恢复文件标签、主题 |
| 左侧大纲 | 标题过滤、点击定位、章节删除与重排；边缘可调宽 |
| 内容区 | 编辑正文；分屏模式有独立预览滚动位置 |
| 状态提示 | 文件载入失败可重试；外改可重新读取；保存错误说明后台保存暂停原因 |

正式 exe 隐藏开发调试入口。自动保存、恢复文件标签初始均关闭；主题默认浅色，复制默认渲染结果。

## 2. 编辑模式、主题和语言

| 模式 | 使用方式 |
| --- | --- |
| 排版成品（WYSIWYG） | 直接编辑排版内容；表格可点击单元格并使用可视化浮层 |
| 语法编辑（IR） | 即时渲染和语法标记混合显示；编辑时会看到部分 Markdown 标记 |
| 分屏预览（SV） | 左侧源码，右侧预览；两个区域分别记忆滚动位置 |

下拉框选择模式，或 Ctrl+Alt+M 循环。模式/语言切换会重建编辑器；中文输入法还在合成文字时，先结束输入再切换、保存、导出或撤销。

主题有浅色、深色、护眼绿、暖纸、Claude Code、跟随系统。Claude Code 为暖炭灰底色、陶土橙强调色和米白正文的深色皮肤。五套主题的六级渲染标题各有颜色，工具栏、面板和独立源码预览同步。切主题不重建编辑器、不修改 Markdown 或撤销记录；导出使用自己的排版，不自动带入阅读背景。“跟随系统”随系统浅/深变化，其他选择保持不变。

支持简中、繁中、英文，记住选择。编辑过的欢迎页切语言会询问是否重置；取消保留原内容。普通未命名笔记不会因为切语言被替换成欢迎内容。

## 3. 标签、保存与关闭

每个标签独立保留正文、撤销和阅读位置。“新建”创建空笔记；保存统一写 UTF-8 无 BOM，打开时识别 UTF-8/BOM/GBK。同路径普通重复打开：没有本地修改则重新读取；有修改则仅激活并保留草稿。点击文档链接到已加载目标时只激活，保留其草稿。

Ctrl+S 保存，Ctrl+Shift+S 另存为；“保存全部”处理当前窗口所有 dirty 标签。全空白保存需明确确认；外部修改导致指纹冲突时会询问覆盖，取消保留本地正文。保存失败或取消另存为后，标签保持原路径；等待写盘期间继续编辑的新修改仍显示未保存。另存为不能占用本窗口其他标签的路径，包括磁盘已删除但标签仍保留的文档；先处理已有标签。损坏且不能完整解码的文件会拒绝打开，请在其他工具中确认编码并保留原始文件。

关闭标签或有修改的窗口时，选择保存、放弃或取消。没有“关闭全部/右侧/其他标签”批量入口。开启“恢复文件标签”也不能代替保存，未落盘草稿不会在重启后恢复。

窗口至少有两个标签时，按住标签名称拖出编辑器客户区并松开，可转到独立窗口。草稿、撤销和磁盘基线一起转移；失败时源标签保留。原窗口关闭后拆分窗口继续运行。暂不支持拖回合并，也不跨启动恢复拆分窗口。

Windows 文件关联需用户选择：右键 .md → 打开方式 → 选择该 exe，并设置始终使用。便携构建不自动替你安装关联。

## 4. 撤销、查找、大纲与表格

光标在编辑区时 Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。每个文档的历史独立，切标签或模式保留；历史有容量预算，大文件可保留的步数会减少。撤回已保存内容时会重新计算未保存标记。

“查找替换”或 Ctrl+F / Ctrl+H 打开面板。输入内容后点“查找”（或 Enter），可选正则与区分大小写，查看上一/下一项，替换当前或全部。搜索的是 **Markdown 源码**，例如跨 `**` 格式标记匹配要按源码书写；结果显示源码行号和上下文，不承诺在富文本正文中选中对应字。修改查询选项或正文后需重新查找；过期、截断或超时结果不用于替换。一次全部替换可以一步撤销。

大纲识别 ATX 标题（# 到 ######），忽略围栏内标题；不识别 Setext 标题。可过滤标题、点击定位、× 删除整个章节及子章节、拖动重排。输入后有短暂防抖，标题已改变时旧章节操作会失效。拖大纲边缘调宽，也可聚焦分隔条用左右键。

排版成品模式点击表格后，浮层可增删行列、对齐、删除表格，数字框输入后 Enter/失焦提交。数据行可上下移动，表头固定；表格操作可撤销。宽表格使用横向滚动条阅读最右列，三模式保持横向滚动。当前没有独立的列宽拖动记忆功能。

## 5. 自动保存、重新读取和历史版本

勾选“自动保存”后，周期及窗口失焦时保存有路径且符合条件的修改；遇到未命名、空白正文、合成输入、重建、外改或错误时不后台强制覆盖。暂停原因会出现在状态区，解决问题并显式保存后继续使用。

外部修改提醒只周期检查激活文档，其他文档在保存时仍核验指纹。“文件已改变”提示中的“重新读取”将读盘；dirty 时先确认。读取等待中若继续编辑，旧结果不会覆盖新修改。外部删除不自动关闭标签，可用另存为保留草稿。

“历史版本”显示覆盖前归档的原始文件版本；选择后预览，再点“恢复为未保存修改”。恢复可撤销，并暂停该文档后台保存；检查内容后 Ctrl+S 才写盘。历史不是未保存草稿备份，也不是跨机器备份。

勾选“恢复文件标签”只保存主窗口有路径标签及激活文件，下次启动按需读盘；不保存未落盘正文、未命名笔记或滚动位置。载入失败可点重试。偏好和历史存于应用本地数据位置，不随 exe 移到另一台机器。

## 6. 文件导航与链接

“文件导航”列出最近文件；“选择文件夹”浏览只读目录。输入关键词后可搜索文件名，勾“搜索正文”则扫描受支持文本；点取消停止接收后续结果。超限、跳过文件或权限错误会有状态提示，结果可能不完整。Ctrl+P 打开快速入口，Ctrl+Shift+P 或输入 `>` 查找当前可用命令。

| 文档中的目标 | 打开方式 |
| --- | --- |
| #标题、file.md#标题 | 文档内定位或打开本地文档后定位；相对路径基于源 Markdown 目录 |
| md/markdown/mdown/txt | 编辑器标签页；已有草稿保留 |
| ts/rs/py/json/toml 等源码或配置 | 默认独立只读预览；指定代码编辑器后交给它 |
| PDF、Office、常见图片 | 系统默认应用；无关联时提示错误 |
| 本机目录 | 资源管理器 |
| http/https/mailto/tel | 系统默认浏览器或关联应用 |
| 程序、快捷方式、未知类型、网络共享/设备路径 | 拒绝打开并提示 |

中文、空格、百分号编码、本机盘符绝对路径和本地 file URL 可用。未保存文档的相对链接需要先保存。标题不存在会提示；本地链接中的查询参数不作为普通文件路径接受。

源码位置写作 `../src/main.ts:12`、`:12:3` 或 `#L12`。只读预览有独立系统标题栏，可拖动、缩放、多开；主编辑器关闭后仍可阅读。预览只读，不支持 Ctrl+S 写回，不追踪外改或下次启动恢复；刷新请重新打开链接。行号超出末行时提示并定位末行，列号交给支持它的外部编辑器。

在预览中“选择代码编辑器…”指定 exe，成功启动后记住选择。支持 VS Code/Insiders、Cursor、VSCodium、Notepad++、记事本；记事本不保证行列定位。Shift+点击源码链接强制重新预览，可换编辑器或恢复默认预览。编辑器失效则回退预览。ps1/bat/cmd/sh 等脚本只作文本查看。

## 7. 图片与复制

在编辑区 Ctrl+V 粘贴剪贴板图片，会创建图片资源并插入 Markdown 引用。等待写入资源期间切换标签、重建编辑器或修改正文，会拒绝迟到插入并提示重试。已有路径文档使用旁边 assets；未命名图片暂存在应用本地 image-drafts。首次保存/跨目录另存为会复制受支持的 Markdown 图片到目标 assets 并改写引用，原图片不删除。图片复制失败或期间正文变化时保留原草稿和身份，按提示重新另存为；已经生成的资源副本可能留存。

相对本地栅格图片在三模式显示；显示覆盖不把 data URI 写进 Markdown，也不标记 dirty。手写带空格路径可使用百分号编码或标准 Markdown 尖括号语法；程序粘贴时生成编码后的普通 URL。原始 HTML img 不参加另存为迁移；缺图、SVG/BMP 等不支持的本地 Markdown 引用可能阻止迁移。

README 中的 HTTP/HTTPS 图片（包括在线 SVG 徽章）可在联网时直接显示，断网或图片服务不可用时显示替代文字，不自动缓存或下载到文档目录。支持跨 Markdown 段落的成对 `<div align="left|center|right">` 和 `<center>` 排版；HTML 标题、链接及图片按正文显示。“排版成品”隐藏容器边界和 HTML 注释，修改这些标签请切换“语法编辑”或“分屏预览”的源码区。段落内普通换行按 Markdown 软换行显示；需要强制换行时使用行末两个空格或 `<br>`。

“复制：渲染”输出富文本 HTML 和纯文本，有序列表序号显式保留；“复制：源码”输出 Markdown。IR 半渲染内容可能保留部分行内标记；SV 选择半行源码时渲染复制可能得到不完整格式。实际粘贴效果还取决于接收应用。

## 8. 导出与打印

在辅助栏选择格式，再点“导出”；等待期间入口禁用，结束/取消/失败后恢复。导出捕获当时的正文、文件名和图片基址，切标签或继续编辑不会串入其他文档。**导出不等于保存 Markdown。**

| 格式 | 当前行为 |
| --- | --- |
| HTML（带样式） | 独立净化 HTML，含标题/表格/代码/引用和打印样式 |
| HTML（纯净） | 独立净化语义 HTML，减少排版样式 |
| Word | 默认 token 后端，包含原生脚注、嵌套编号、中文排版、代码高亮、表格与图片 |
| Word（兼容后端） | HTML→docx 及 OOXML 后处理；复杂 HTML 可尝试此格式，脚注与新后端表达不同 |
| PDF | 应用已有 WebView2 离线生成 A4，无需独立 Edge 浏览器或 Office |
| PNG 图片 | 固定宽度长图，超长提示改用 PDF 或拆分文档 |
| 打印… | 独立窗口打开系统打印界面；用户选择打印机并确认，完成或取消后关闭承载窗口 |

本地 PNG/JPEG/GIF/WebP 与有效栅格 data URI 可嵌入，产物无需原图片目录。Word 转为 PNG 静态画面；公式/Mermaid 离线转图片，不能作为可编辑 Word 数学对象。远程图片不下载；缺图、损坏、超限或不支持的图片保留说明，完成提示列出原因。两套 Word 后端不会因错误自动互相切换。

## 9. 快捷键与常见处理

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 编辑区撤销 / 重做 |
| Ctrl+F / Ctrl+H | 源码查找替换面板 |
| Ctrl+P / Ctrl+Shift+P | 文件快速入口 / 命令入口（不是直接打印快捷键） |
| Ctrl+Alt+M | 循环编辑模式 |
| Ctrl+B / Ctrl+I | Vditor 加粗 / 斜体 |
| Ctrl+C / Ctrl+V | 所选模式复制 / 粘贴（含图片） |

保存冲突时先检查磁盘版本，决定重新读取、另存草稿或明确覆盖；自动保存不会替你做选择。重新读取入口出现在外改状态提示中，不是常驻工具栏按钮。打不开附件先检查格式及系统关联；打不开远程图符合离线策略。源码预览太大或想编辑源码时选择代码编辑器。导出超限时拆分文档或改格式，具体门禁见[能力边界与限制](能力边界与限制.md)。

构建与自动化测试统一见[构建说明](构建exe全流程.md)，本指南不再维护第二套开发命令。
